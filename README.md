# SnapFlow

## Install

```bash
./scripts/pnpmw setup
```

## Development

```bash
./scripts/pnpmw dev
```

## Test

```bash
./scripts/pnpmw test
./scripts/pnpmw lint
./scripts/pnpmw typecheck
./scripts/pnpmw build
```

## Format

```bash
./scripts/pnpmw format
./scripts/pnpmw format:check
```

## Web

```bash
./scripts/pnpmw dev:web
```

## API

```bash
./scripts/pnpmw dev:api
```
